Professional Web3 hybrid payment gateway for WooCommerce with MetaMask and GOLDT ecosystem tokens support.

== Description ==

**GOLDT Web3 Hybrid Payments** enables both Web3 cryptocurrency payments via MetaMask and traditional Web2 payment methods as a fallback.

= Key Features =

* MetaMask Integration
* GOLDT Ecosystem Tokens (GOLDT, GOLDVE, BNBV, GPOOL, FGVAULT)
* Real-time Oracle Pricing
* Web2 Fallback
* Multi-chain Support
* Transaction Logging
* GPL Licensed

See full documentation in README.md

== Installation ==

1. Upload plugin to WordPress
2. Activate the plugin
3. Configure in WooCommerce → Settings → Payments
4. Enter wallet address and configure settings
